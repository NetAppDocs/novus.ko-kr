= Novus Data Director 사용 방법에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Novus Data Directors(NDD)는 Novus 메타데이터 계층의 핵심 역할을 하며, MDS 노드 전체에 걸쳐 메타데이터의 배포 및 소유권을 관리합니다. NDD 명령줄 인터페이스를 사용하여 관리 작업을 수행할 수 있습니다. NetApp Novus를 운영 환경에 구축하기 전에 관리 구조와 구성 옵션을 이해하는 것이 중요합니다.



[[novus-command-line-interface]]
== Novus 명령줄 인터페이스

활성 MDS 호스트 중 하나의 Linux 명령줄 인터페이스에서 Novus Data Director를 관리합니다. 로컬 또는 SSH를 통해 MDS 호스트에 연결할 수 있습니다. NDD 명령줄 인터페이스에서 사용할 수 있는 두 가지 주요 툴이 있습니다.

mds-admin:: 아래에 설명된 여러 영역에서 단일 노드 인스턴스(하나의 네임스페이스)에서 작동합니다. 이 명령은 pnfs-mds 관리 엔드포인트(기본적으로 포트 50051)에 연결합니다.
ndd-admin:: NDD 배포 환경 전체(모든 호스트 및 네임스페이스)에서 작동합니다. 호스트를 준비하고, 네임스페이스를 프로비저닝하며, 백업 및 복원, 키 순환, 업그레이드 등 관리 및 유지 관리 작업을 처리할 수 있습니다. 필요에 따라 사용자를 대신하여  `mds-admin` 명령을 실행합니다.




[[use-mds-admin-to-perform-novus-administration]]
==  `mds-admin`을(를) 사용하여 Novus 관리를 수행하십시오.

NDD CLI를 사용하면 Novus Data Director에서 다양한 관리 작업을 수행할 수 있습니다. 이러한 작업은 몇 가지 범주로 나뉩니다.


CAUTION: NDD에서 명령을 실행할 때는 주의하십시오. 일부 명령은 시스템 상태를 변경하거나 더 높은 위험을 수반할 수 있습니다. 노드 명령 (`force-remove`, `subtree-unlink`, `backup restore`) 등 다른 명령은 손상을 초래할 수 있습니다.

상태, 진단 및 지원::
+
--
* NDD 클러스터 상태 확인
* 지원 번들을 수집하고 프로토콜 버전을 출력합니다
* 크래시로 인해 남겨진 파일과 기록을 정리합니다.
*  `mds-admin` 작업 로그를 확인하거나 복구하십시오.


--
MDS 클러스터 멤버십 및 업그레이드::
+
--
* MDS 노드를 추가, 드레인, 분리 또는 제거하고 대기 복사본을 연결합니다.
* 롤링 업그레이드를 실행하고 구성 변경 사항을 한 번에 한 노드씩 적용합니다


--
메타데이터 소유권: 네임스페이스가 MDS 노드 전체에 어떻게 분할되는지::
+
--
* MDS 노드 간 서브트리를 나열, 이동, 분할 및 재할당하고 자동 분할 제안을 승인합니다.
* 샤드 균형을 재조정하고 경로가 배치되는 위치를 설명합니다


--
데이터 서버(ONTAP 백엔드) 관리::
+
--
* 데이터 서버를 등록, 제거, 검증 및 드레인하고 상태를 설정합니다.
* MDS 호스트에서 용량 확인, 배치 가중치 설정, 다중 경로 주소 및 NFS 버전 설정, 데이터 서버 마운트 관리를 수행합니다.
* 엑스포트에 대한 소유권 마커를 확보하고 데이터 서버 호스트의 인벤토리를 유지하십시오.


--
데이터 배치 및 보호::
+
--
* 파일이 저장된 데이터 서버를 찾은 다음, 파일을 이동하거나, 재매핑하거나, 미러를 추가하십시오.
* 데이터 서버에 미러를 복구하고, 데이터 서버 간에 미러를 이동하고, 목표 미러 수까지 파일을 백필합니다.
* 미리 생성된 파일 풀을 관리합니다
* 티어링 켜기 또는 끄기
* HPC 경로에 대해 와이드 스트라이핑을 켜거나 끕니다


--
네임스페이스 정책 및 데이터 관리::
+
--
* 할당량을 설정하십시오
* 경로에 메타데이터 태그를 추가하고 태그로 검색하십시오
* 메타데이터 카탈로그를 백업, 검증 및 복원합니다


--
클라이언트, 테넌트 및 추가 프로세스::
+
--
* 클라이언트 세션 만료를 강제하고, 클라이언트 복구 기록을 정리하고, 클라이언트 ID 기록을 관리합니다.
* 복구 후 VIP 라우팅 처리
* 테넌트 생성, 일시 중지, 재개, 스냅샷 생성, 복원, 마이그레이션 및 제한
* 도우미("동반자") 프로세스의 리소스를 등록하고 제한합니다


--




[[getting-started-using-the-ndd-cli]]
== NDD CLI 사용 시작하기

시작하려면 몇 가지 기본 명령어를 입력하면 됩니다.

.이 작업 정보
기본적으로 `mds-admin`는 로컬 호스트(포트 50051의 127.0.0.1)의 메타데이터 서버에 연결합니다. 다른 NDD 인스턴스에 연결하려면 옵션 `--mds-host <address>`을 `--mds-port <port>`과 함께 사용하십시오. 호스트의 관리 주소가 아닌 MDS 주소를 사용해야 합니다.

.시작하기 전에
MDS 호스트의 IP 주소 또는 호스트 이름과 해당 호스트에 대한 SSH 액세스 권한이 필요합니다. 또한 루트 사용자로 로그인하기 위한 적절한 자격 증명이 필요합니다.

.단계
. SSH를 사용하여 MDS 호스트에 연결합니다.
+
`ssh root@<mds-host>`

. 릴리스 및 프로토콜 버전을 표시합니다.
+
`mds-admin -V`

. 명령어 사용에 대한 도움말을 확인하세요
+
[listing]
----
mds-admin --help
mds-admin help status
mds-admin help "ds list"
----
+
참고로  `--help`은(는) 사용 가능한 모든 명령을 나열하고  `help <command>`은(는) 특정 명령에 대한 옵션을 표시합니다. 여러 단어로 된 전체 명령은 큰따옴표로 묶으십시오.  `mds-admin help -k <keyword>`을(를) 사용하여 키워드로 검색할 수도 있습니다.
