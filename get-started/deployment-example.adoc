[[high-performance-storage-hps-network-architecture]]
== 고성능 스토리지(HPS) 네트워크 아키텍처

1024개의 GPU를 사용하는 구축 환경에서는 최신 세대 GPU의 표준 성능 요구 사항을 충족하기 위해 총 3대의 NetApp Novus 스토리지 시스템용 AFF A90과 3대의 Novus Data Director(NDD) 서버가 필요합니다. 다음 그림은 이러한 구성과 해당 규모의 시스템에 대한 관련 HPS 네트워크 아키텍처를 보여줍니다.
